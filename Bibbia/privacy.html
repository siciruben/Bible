Informativa sulla privacy di Bibbia

Ultimo aggiornamento: 27 novembre 2026

Chi siamo

Bibbia è un'app web gratuita per leggere e studiare la Bibbia. Contatto: siciruben@gmail.com.

Dati salvati sul tuo dispositivo

Preferenze, evidenziazioni, note per versetto, segnalibri e cronologia restano nella memoria del tuo browser. Non vengono inviati a nessun server dell'app.

Blocco note e Google Drive (beta)

Se scegli di collegare Google Drive, l'app ti chiede un solo permesso, quello di creare e gestire i file creati dall'app stessa (accesso «drive.file»). Le tue note vengono salvate come file di testo in una cartella «Bibbia Note» nel tuo Drive.

  • L'app non può vedere né modificare gli altri file del tuo Drive.
  • Le note e l'accesso al tuo account passano direttamente tra il tuo browser e Google. Non esiste un server dell'app e lo sviluppatore non riceve, non legge e non conserva le tue note né i tuoi dati personali.
  • Puoi scollegare l'app dal pulsante «Scollega», oppure revocare l'accesso in qualsiasi momento dalle impostazioni del tuo account Google.

L'uso dei dati ricevuti dalle API di Google rispetta la Google API Services User Data Policy, inclusi i requisiti sull'uso limitato.

Servizi di terze parti

Per funzionare, l'app può contattare servizi esterni: i font di Google Fonts, i testi biblici e i commentari ospitati online, e servizi di traduzione automatica quando usi la funzione «Traduci» (il testo del capitolo viene inviato a quei servizi). Ogni servizio applica la propria informativa.

Cookie e pubblicità

L'app non usa pubblicità né strumenti di tracciamento.

Modifiche
